# Sistem Pengaduan Fasilitas Kampus

Tujuan: membantu mahasiswa melaporkan kerusakan fasilitas kampus dan memantau penanganannya.

## Struktur Proyek
- requirements/ : SRS dan daftar kebutuhan
- uml/ : diagram use case, activity, class
- src/ : kode aplikasi
- test/ : skenario dan hasil pengujian
- .gitignore : daftar file yang tidak dilacak Git
